# Rakesh Pokala — 3D Java Backend Developer Portfolio

A responsive, futuristic portfolio built with React, Vite, React Three Fiber, Three.js, Drei, Framer Motion, and Lucide icons.

## Run locally

1. Install Node.js LTS.
2. Open a terminal in this project folder.
3. Run `npm install`
4. Run `npm run dev` and open the local URL printed by Vite.

Create and preview a production build with `npm run build` and `npm run preview`.

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the repository.
4. Vercel should detect Vite automatically. Use:
   - Build command: `npm run build`
   - Output directory: `dist`
5. Click **Deploy**.

A `vercel.json` file is included with an SPA fallback rewrite. The site is static; no environment variables are required.
